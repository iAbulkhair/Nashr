# Coverage: workspace name, invite decline and the folding rail (rules 3115-3129)

Status on 2026-10-23 on branch `claude/sup-workspace-ui` (flows.md section 127). Three ideas from Supastarter's organization settings, invitation page and sidebar, built on Thakeen's own code. Release step: expand. No stored shape changes for the rename (`workspaceName` is the account field M2 already writes and reads). The team log gains the kind `invite_declined`, appended to `TEAM_LOG_KINDS`, and its actor's `pid` becomes optional; an older build drops a row of an unknown kind on read, so a rollback hides those rows and nothing else. New rate buckets `wsname:{acct}` and `team:decline:ip:{ip}`; one new browser cookie `thakeen_rail`. No environment variable. Rules 3115-3127 are used; 3128-3129 are free.
