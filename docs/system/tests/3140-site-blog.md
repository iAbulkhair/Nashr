# Coverage: blog tags, per-page share images, llms-full.txt (rules 3140-3143)

Status on 2026-10-23 on branch `claude/sup-site-blog`. Three public-site items taken from supastarter's blog and docs apps (the ideas; the code is ours): optional blog tags with a server-side `?tag=` filter, one share-card maker used for each blog post and each help topic, and `/llms-full.txt`. Rules 3144-3149 are reserved and unused. Release step: expand only, no stored shape changes (the front matter fields are optional and files, not Redis, hold them); the blog index becomes a per-request page because it reads `?tag=`.

| 3140 | A post may carry `tags_ar` and `tags_en` (comma or Arabic comma separated, at most 5 each, none empty, repeated in any case or longer than 30 characters); a post tagged in one language is tagged in both (`postProblems`, so `next build` fails on a bad file). The blog index lists every tag as a plain link to `/{lang}/blog?tag=...` (`PostTags`, no client code), the active one `aria-current="page"`; the server filters the posts without regard to letter case; a tag nobody carries shows an empty state with a link back; a filtered view is `noindex,follow` with the whole index as canonical. | 3141 | One card maker, `shareCard` in `src/lib/share-card.tsx`, draws a 1200 by 630 PNG from a title (and a description) in the brand's tokens (ink on lemon, from `assets/design-tokens.json`), in the site's Arabic display font, set right to left in Arabic and left to right in English, with no claim, number, customer or model name of its own: only the page's words, the public name and the kind of page. The font files stay unmodified on disk: `woff2ToSfnt` (`src/lib/woff2.ts`) unwraps them in memory, because Satori cannot read WOFF2, and only the drawn pixels leave. Arabic is written in its joined forms by `shapeArabic` (`src/lib/arabic-shape.ts`) because Satori measures each letter in its isolated shape; a lam and an alef are drawn as two joined letters, not the ligature, which this font keeps as empty glyphs. A title that fits on one line sits on the reading side. A long title or description is cut at a word with an ellipsis (`clip`); a longer title takes a smaller size. | `tests/share-card.test.ts` (WOFF2 unwrap of all three weights and the file untouched, the joined forms and their visual order, marks, a run of plain letters written backwards for the engine, a one-line title on the reading side read from the PNG's pixels, PNG size in both languages, `clip`, `titleSize`, `cardAlt`, no hard-coded colours or model names) | none |
