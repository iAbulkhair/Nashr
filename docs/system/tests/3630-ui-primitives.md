# Coverage: UI primitives, Popover, Tooltip and components.json (rules 3630-3636)

Status on 2026-10-23 on branch `claude/sup-ui-primitives`, built on `claude/dialog-scroll-lock-menu-typeahead` (rules 3200-3201). The founder compared Base UI with the hand-made components and kept the hand-made ones, so these rules add small primitives to `src/components/ui/` and no UI library: no Base UI, no Radix, no tailwind-merge, no clsx. Rules 3637-3649 are reserved and unused. The suite has no DOM, so Escape, click-away and focus return are pinned as pure decisions (`closesOnKey`, `isOutside`, `closesOnFocusMove`, `tipStep`) plus source pins on the wiring; a browser test is the first test still to write.
