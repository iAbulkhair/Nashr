## Notes

- The in-memory store (`memory()` in `src/lib/db.ts`) keeps an expiry only on plain keys, so `expireNx` on a list does nothing there. Rule 793's 31 days is pinned by the call (`expireNx(key, 2678400)` after the push, `ltrim(key, 5000)`), not by reading the TTL; Upstash applies it to the list.
- `otherBrandNames` lists every other brand of the account, archived ones included (`listBrands` returns them). Not pinned either way.
- The classifier and `scopeCheck` are rule 791 (Task 2). The gates that call `scopeCheck` and the founder's routes are later tasks; their rules are the range row above until the tasks that add them.
- Rule 795: the burst ceiling (`chatRefusal`, rule 331) runs in the same round as the preflight, so it has counted a request that the agent-scope ceiling then refuses. Accepted: one extra burst count per refused request, and it keeps the gate to one round of reads.
- Rule 794: `tests/chat-trial.test.ts` and `tests/model-timeouts.test.ts` count model clients or calls, which the default shadow classifier would add to; each sets the modes off in a `beforeEach` (input `off`), assertions unchanged.
- Rule 791 adds the purpose `agentScope` (the ninth) to `route()`. Row 820 in `docs/system/tests.md` is an existing rule, so it was edited in place (rule 788 only forbids adding rows there): it now says nine purposes, with `agentScope` on Haiku 5.5 and not overridable; `tests/model-route.test.ts` pins nine. `agentScope` is not in `OVERRIDABLE`: a stored pick never changes it.
- The "Haiku is priced as Haiku" check reads the `RATES` row in `src/lib/usage.ts` as text (the table is private) and also compares the catalog's rate, which `costUsd` asks first.
