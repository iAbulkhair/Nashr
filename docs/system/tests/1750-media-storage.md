Status on 2026-10-13 on branch `claude/media-storage-5d8cb6` (cut from main `28e784d5`), draft PR, not merged, not live. Founder decision of 2026-10-13: images and video move from Vercel Blob to Hostinger's disk, private by default, deleted with the account. The privacy policy's date moved to 2026-10-13, so `PRIVACY_VERSION` changed (rule 1325). Rules 1767-1774 are held and not used.
