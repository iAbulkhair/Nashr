# Coverage: auth and mail polish (rules 3100-3114)

Status on 2026-10-23 on branch `claude/sup-auth-mail`, not pushed. Four items brought from Supastarter's auth and mail packages, written in Thakeen's own code with no new dependency: a 72-byte password cap, "Set a password" for a login without one, a "last used" sign-in hint, and reply-to on outgoing mail. Release step: expand only, and nothing to contract. No stored shape changes: the reset record (`pwreset:{hash}`) and the per-address bucket (`forgot:em:{email}`, now built by `globalKey.resetLinkBucket`) are the forgot route's own; the one new cookie (`thakeen_last_login`) holds a method name and nothing reads it on the server. No environment variable is added (`SUPPORT_EMAIL` is a code constant in src/lib/i18n.ts).
