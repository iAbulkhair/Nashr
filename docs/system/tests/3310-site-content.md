| 3310 | The tag helpers of rule 3140 are pinned at their edges: `splitTags` collapses inner whitespace and line breaks and keeps a stray comma as an empty piece; `tagKey` ignores case and spacing; `tagProblems` accepts exactly `MAX_TAGS` tags of exactly `MAX_TAG_LENGTH` characters, names every problem at once, and reads empty pieces as empty, never as a repeat; a front matter value of blanks is no tags; each language is checked on its own; `tagFromParam` takes the first value only; `filterByTag`, `allTags`, `isActiveTag` and `blogHref` agree on case, spacing, Arabic and characters that end a query. | `tests/blog-tags.test.ts` (block "edge cases of the tag helpers") | none |
| 3311 | A post stays Markdown (no MDX or remark/rehype package, so a post can never run code or load a component). Fenced code (three backticks or tildes, any longer fence closing only on the same mark at least as long, unclosed ones closing at the end) renders as `<pre class="code" dir="ltr" tabindex="0">` with `<code class="language-x">`; its text is escaped and never read as Markdown, blank lines are kept, and a language name outside `[A-Za-z0-9_+#.-]{1,24}` is dropped. Highlighting happens on the server only: `render(md, { highlight })` takes a `CodeHighlighter` option, `src/lib/md-highlight.ts` builds one with Shiki (`shiki` in `package.json`, an exact version released more than a week before it was added, JavaScript regex engine, `nord`, thirteen languages), and `render` escapes every token and accepts a colour only as `#hex`, so a hostile highlighter or a hostile post writes nothing but escaped text. `md.ts` imports no highlighter, so chat, the inbox and the emails load none. Script and HTML injection (tags, event handlers, `javascript:`/`data:` links, attribute breaks, entities, fences) stays neutralised in every shape: the output holds only the tags and attributes `render` writes, for the attack list and for every real post. | `tests/md-rich.test.ts` (fence block, escaping, highlight for every loaded language with the text unchanged, a hostile highlighter, no MDX, the injection list in both languages, every real post) | none |
| 3312 | Links go through `render`'s options: with `lang`, an internal path takes the page language (`/pricing` becomes `/ar/pricing`, a language already there is replaced by the page's, `/p/...`, `/api/...` and files are left alone; `LINK_SEGMENTS` equals the proxy's `PUBLIC_SEGMENTS` plus `app`); with `origin`, an absolute link to this site is read as internal after `safeNext` checks the parsed path (`https://site//evil` stays an external address, never `//evil`).
