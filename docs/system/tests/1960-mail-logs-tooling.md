# Coverage: mail, logs and tooling from the supastarter gap study (rules 1960-1979)

Status on 2026-10-16 on branch `claude/funny-lehmann-37da27` (cut from main e3b9f708). The supastarter gap study of 2026-10-16 listed quick wins in email, observability and tooling; the founder's standing order is «the best of supastarter in all aspects». The code is ours: supastarter was read as a reference only, and there is no react-email (it throws under `react-server`) and no new dependency. What the site already did better stays: the escaped right-to-left email tables, the audit log, the cron heartbeat and the SEO basics. `flows.md` section 78. Rules 1967-1969 are held for this area. No environment variable added; one admin page and one optional request field added (`permissions.md` row 24 and the console sections).

Not moved onto the typed `sendEmail`: `src/app/api/auth/forgot/route.ts` (owned by another session; it keeps the positional form, which still works), the support forward and the staff alert (text only, to the team).
