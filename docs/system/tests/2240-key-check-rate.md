# Coverage: failed key checks limited per workspace, and a deadline on every connect call (rules 2240-2249)

Status on 2026-10-19 on branch `claude/api-platform-integrations-ce2972`. `POST /api/connect/{provider}/key` checks the credentials it is given against an outside service (a WordPress site's username and application password, a WooCommerce, Odoo or PrestaShop key, a Telegram bot token, a Brevo or Klaviyo API key) and had no rate limit, so a signed-in account could use Thakeen's servers to try passwords against any WordPress site. Failed checks now cost a hit in two buckets of the caller's own workspace (flows section 12 step 2a); a passing check hands its hits back. Rule 2241 gives the Klaviyo key check (the one direct `fetch` of the route) the 30 s `providerTimeout()` deadline every other provider call has (rules 1343-1344), and widens the rule 1344 source scan from eight named connector files to every file under `src/lib/connectors` and `src/app/api/connect`, so a new call without a deadline fails the check. Rule 2242 limits connect starts to twenty an hour per workspace, because each Composio start opens a pending connection on the one Composio account every tenant shares (flows section 11 step 1a). Rule 2243 limits the manual sales sync (open to any member) and the product import to six an hour each per workspace, because each reads pages from the store (flows section 11 step 11a). Rule 2244 stamps a pending Shopify store with the time Shopify fired the uninstall or `shop/redact`, so a delivery retried after the owner connected again no longer drops the new grant (flows section 11 step 14t). Rule 2245 reads every reply of an owner-supplied host (WooCommerce, Odoo, PrestaShop, WordPress) up to an 8 MB cap, so one hostile store cannot fill the instance's memory (flows section 12 step 3b). Rule 2246 does the same for pages and sitemaps of a site a user names (the onboarding crawl and the no-key catalog import): only the first 2 MB are read, and the crawl's 9 s deadline now covers the body, which it used to clear before reading it (flows section 6 step 5). Rule 2247 writes every imported product line through one helper that makes each field plain, capped text and keeps a link only on the store's own host (flows section 11 step 10c). Rule 2248 moves the no-key catalog import onto the same helper, keeps its sitemap links on the site's own host, and stops an import that found nothing from emptying `products.md` (flows section 11 step 10d). Rule 2249 puts the no-key catalog import (the Files page and chat's `import_catalog`) in the store import's bucket, six an hour per workspace in all (flows section 11 step 11a).
