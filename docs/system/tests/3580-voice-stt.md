# Coverage: voice notes in the chat composer (rules 3580-3599)

Status on 2026-10-23, branch `claude/sup-voice-stt` (not pushed). Speech-to-text for the chat composer: a microphone button records a note of up to two minutes, `POST /api/chat/voice` turns it into text with ElevenLabs Scribe v2, and the text lands in the message box for the person to edit and send. Off unless `VOICE_STT_PROVIDER` names a provider whose key is set. Spec `docs/superpowers/specs/2026-10-23-voice-stt.md`, flows section 122, permissions row 31c. Every provider call in the tests goes to a stubbed `fetch`; no paid API is called. Release step: expand only, no stored shape is added or changed.
