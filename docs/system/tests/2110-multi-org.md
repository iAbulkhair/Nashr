Status on 2026-10-19 on branch `claude/wave3-m1-expand` (spec `docs/specs/2026-10-18-multi-org.md`, plan `docs/superpowers/plans/2026-10-19-multi-org-m1.md`). Release step: **M1 = expand** (rule 679): the new code reads the old and the new shapes, writes both for a home membership, and older builds ignore every new key and field, so a rollback to any earlier build is safe. `MULTI_ORG` is `false` through M1, so production behaves as today (rule 2132).
