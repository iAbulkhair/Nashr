# Coverage: the home cover's call to action under the team, and the figures' own turns (rules 1830-1835)

Status on 2026-10-13 on branch `claude/home-hero-cta-1830` (cut from main 9e775467). The founder's review of the home hero on 2026-10-13 (Arabic, translated): "The CTA is in the wrong place. Put it under the characters. The messages above each character should move continuously on their own; right now they only show when the mouse/touch passes over them." Before this change the cover's signup form, trial line and freshness chip (rules 1228, 1229) sat under the offer, above the team, and a figure's thought cloud showed only on pointer, keyboard focus or a tap (rule 515). No route, permission or environment variable changed; no copy changed. Rules 1836-1839 are held for this change and not used.
