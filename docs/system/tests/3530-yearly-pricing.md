# Coverage: yearly billing next to monthly, off until the founder sets a price (rules 3530-3542)

Status on 2026-10-23, branch `claude/sup-yearly-pricing`. Pushed together on `claude/sup-yearly-pricing` with main merged in (2026-10-24), as one draft PR. Yearly billing is built through pricing, checkout, the callback, renewals, the provider seam and the pricing page, and is inert: every yearly price in `src/lib/pricing.ts` is null (the founder has set no amount), so the site, checkout and billing behave as on main. With the prices null the `/pricing` and industry-page markup, the home plans and the pricing dictionary were compared byte for byte against main before the commit: identical. `tests/yearly-pricing-on.test.ts` sets a test-only yearly price inside its own module graph (Starter 2,990 SAR, Pro 2 months free) to prove the rest; those numbers are not prices. Release step: expand (flows.md section 110.1): an optional `interval` on `Billing` and `PayIntent`, absent read as monthly. The founder sets a yearly price only after this release is live. Rules 3543-3549 are reserved and unused.
