# Coverage: customer cloud drives and the media library (rules 1775-1799)

Status on 2026-10-13 on branch `claude/cloud-drives-5d8cb6`, cut from `claude/media-storage-5d8cb6` (rules 1750-1774, draft PR #363), draft PR, not merged, not live. Founder request of 2026-10-13: customers link Google Drive, Dropbox and OneDrive to import brand files and media into Thakeen and to export finished media to their drive; iCloud through the normal upload. Every drive goes through Composio (toolkits `googledrive`, `dropbox`, `one_drive`, pinned); no direct OAuth app. Dormant until the founder sets `COMPOSIO_AUTH_GOOGLEDRIVE`, `COMPOSIO_AUTH_DROPBOX`, `COMPOSIO_AUTH_ONEDRIVE` and adds the three provider ids to `COMPOSIO_PROVIDERS` (Composio itself must be live). New routes `GET`/`POST`/`DELETE /api/drives` and `POST /api/media/upload`; new role actions `library.write` and `library.export` (member). Stored shape: a media index entry gains an optional `source` (expand only: old entries without it read as a post's media, rule 679). Flows section 72. Rules 1790-1799 are held and not used.
