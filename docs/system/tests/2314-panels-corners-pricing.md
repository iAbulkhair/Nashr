# Coverage: splash panel, one colour band, one corner rule, pricing page (rules 2314-2319)

Status on 2026-10-19 on branch `claude/thakeen-frontend-eval-49730a`, after rules 2310-2313 (`2310-home-first-screen.md`). This is the second batch of fixes from the same design review. On home, every panel row was four equal frames on the same ground. On pricing, the page had eyebrow labels, a monospace credit table, ruled rows and no motion. The review also asked for one written rule for corners, because the tokens held two card radii (12px and 6px).

All six rules were checked in a browser on the local dev server, in Arabic and English. Home was seen at 1440x900, 768x1024 and 390x844, and pricing at 1440x900. None of these sizes scrolls sideways.
