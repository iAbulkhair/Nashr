## Not pinned

- B-5 at run time. The bug was confirmed by reading the code: ChatPanel keeps `useState(initial)` and `useState(initialConv)`, its effect resets only the agent, and the sidebar's `?conv=` / `?agent=` links are client navigations to the same page. It could not be reproduced in a browser in the session that wrote this: the local dev server could not bind a port in the sandbox. Row 962's first test is the browser check.
- Left from the report's phase 0 row (§7) and not in this change: Plex 700 or a weight cap, trimming the font preloads, "coming soon" in paid-tier bullets, `hello@nashr.ai`, a 44px mobile nav trigger, Arabic `aria-label`s throughout, `text-left` to `text-start`, mirrored arrows, Western digits. The home type scale (`--t-xs` = `--t-s` = 16px) is unchanged: 16px is the floor for Arabic body text there, and changing the steps is a design decision.
- The other native `confirm()` and `prompt()` calls in the founder console (deal apply, void, refund, the number prompts) stay until the `FormDialog` / `PromptDialog` work of the report's §5.
