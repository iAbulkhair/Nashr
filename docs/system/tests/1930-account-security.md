# Coverage: customer account security (rules 1930-1956)

Status on 2026-10-16 on branch `claude/beautiful-blackburn-50e6d7` (cut from main e3b9f708). The supastarter gap study of 2026-10-16 (wave 1, customer auth) found that customers had no two-step sign-in, no list of their signed-in devices, no way to change their sign-in address and no Google sign-in, while the founder console already had a second factor. This change builds all four on Thakeen's own code (the staff TOTP, keyring and hashed recovery codes; the typo-fix move of rules 763-765) and makes account deletion stop Paymob renewals first. Flows in `docs/system/flows.md` section 80, permissions rows 242-248 and "Account security", variables `GOOGLE_SIGNIN_CLIENT_ID` and `GOOGLE_SIGNIN_CLIENT_SECRET`, spec `docs/specs/2026-10-13-google-sign-in.md`. Rules 1957-1959 are held for review fixes.
