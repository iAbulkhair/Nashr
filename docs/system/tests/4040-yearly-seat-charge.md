# Coverage: a mid-year seat on a yearly subscription is charged now (rules 4040-4059)

Status on 2026-10-24, branch `claude/yearly-seat-charge-06f3aa` (from 64139f84: yearly pricing with paid seats #455, main and Geidea #456). Pushed together on `claude/sup-yearly-pricing` with main merged in (2026-10-24), as one draft PR. On a yearly subscription the next renewal is up to a year away, so a seat bought mid-year and "charged from the next renewal" (rule 3370) would be free for months. Instead the owner's one extra seat is charged right away on the saved card for the months left of the paid year: months left × 25 SAR + VAT, priced in code by `priceFor("seat")`. The seat and the invite exist only once the charge is paid. Monthly plans are unchanged. Flow: `docs/system/flows.md` sections 110 (item 10) and 121 (items 4-6). Release step: **expand** only (a new intent kind `seat`, new optional `seatMonths` / `seatThrough` on an intent, two new account keys `pay:seatlock:{email}` and `pay:seatwait:{email}`; old code never writes them and ignores them on read). Rules 4053-4059 are reserved and unused.
