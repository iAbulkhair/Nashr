# Coverage: a model pick is priced against the type's own writer (rule 902)

Status on 2026-10-10 on PR #298 (model routing, rules 810-866), merged with main after #310 (rule 901, `TASK_MODELS`) and #304 (admin shell). Founder decision relayed by the coordinating session: option A, "use our last decisions … but still we need to use Straitly" (spec `docs/superpowers/specs/2026-10-08-straitly-model-routing-design.md`: x1 = today's price and the floor holds per model; #310: route() reads `TASK_MODELS`).

- `route("generate", { task })` and `route("review", { task })` default to `TASK_MODELS[task].write` / `.review` (`automaticFor` in `src/lib/models/route.ts`). Without a task, or with one that is not exactly a task type, the purpose's `DEFAULTS`. This closes the last "Not pinned" item of 0901: `TASK_MODELS` now sits behind `route()`.
- `pricedAt("generate", type)` is that type's writer, so `tierMultiplier(model, "generate", type)` is relative to it: Automatic is always x1 (no customer price moved), Opus 5.5 on a Sonnet-written type x2, Sonnet 5.5 on an Opus-written type x0.5, rounded up as `creditsFor` did before. `generateBatch` charges `creditsFor(base, model, "generate", type)` once and refunds the same value. `PRICED_AT.generate` (Opus 5.5) stays for a caller without a task.
- GET /api/models adds `generateByTask` (per type, per model id the type allows, the server's multiplier; no rate). The brand picker shows the range over the types, e.g. `x1–2` for Opus 5.5; an older server's answer without the key falls back to `multipliers.generate`.
- The floor over the catalog prices every `auto`/`pick` model on every type it allows at its per-type multiplier, cold. Every pair keeps the floor (dearest: Opus 5.5 $0.0515, Sonnet 5.5 $0.0482 per charged credit; none above 95% of the ceiling), so the article exemption and Sonnet 5.5's allow-list (no `article`, `followup_seq`) are gone. A type that misses the floor goes in that model's `tasks`; the floor is never lowered.
- The Straitly provider path is untouched: `LLM_PROVIDER` unset is Anthropic direct; production only on the founder's explicit yes.
