# Coverage: SMTP mail provider on Nodemailer (rules 3570-3579)

Status on 2026-10-23 on branch `claude/sup-mail-smtp`. The founder agreed to "SMTP provider adapter (Nodemailer)" from the supastarter comparison, used as a fallback. Mail goes through the provider seam in `src/lib/mail-provider.ts`; this adds a third provider, `smtp`, behind the same interface. Release step: expand only; nothing changes while the `SMTP_*` names are unset, and no stored shape changes. The dependency is `nodemailer` 10.1.2 (published 2026-10-16, past the 7-day gate of rule 699), pinned exactly; it ships its own types, so `@types/nodemailer` is not added. The lockfile was extended in place (one package entry), not re-resolved from scratch, so no unrelated package moved; the `@rolldown/binding-linux-*` entries are all still there (21).
