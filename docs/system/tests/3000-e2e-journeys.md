# Coverage: more end-to-end journeys (rules 3000-3005, 3007-3008)

Status on 2026-10-22 on branch `claude/thakeen-nashr-review-tests-292d14`. Six more Playwright specs drive whole journeys against the test server (`e2e/web-server.ts`, mock model, memory store). They run on `chromium-desktop` only: they sign their own accounts up (each on its own simulated address, `simulatedIp`) and would trip the per-IP limits on a second profile, so `playwright.config.ts` lists them in the `mobile-safari` `testIgnore` and each spec skips itself on any other engine. They were type-checked and listed (`npx playwright test --list`) but not run by their author; the first run is the reviewer's or CI's. Release step: none (tests only).
