# قائمة مميزات المنافسين مقابل ذكين

آخر تحديث: 2026-09-29. المصدر: دراسة السوق وتفكيك الصفحات الرئيسية لثمانية منافسين (Enrich Labs، Sintra، Okara، Jasper، Adly، هلا AI، بي ترند، بوابة التميز) مع Store Tools ولهجتي. حالة ذكين مأخوذة من الكود (`src/lib/tasks.ts`، `src/lib/connectors/registry.ts`، صفحات `src/app/[lang]/app`) لا من صفحات التسويق.

**مفتاح الحالة:** «موجود» = يعمل اليوم. «جزئي» = موجود بشكل ناقص (مثلاً OAuth دون استخدام فعلي). «لا» = غير موجود. عمود **أمنية** = مرشح لصفحة التحديثات والأمنيات (نعم / لا). الأولوية: أ (الآن)، ب (خلال الربع)، ج (لاحقاً).

هذا الملف مرجع داخلي. لا يُنشر كما هو، ولا يُذكر فيه رقم عن منافس إلا من مصدره في الدراسة.
