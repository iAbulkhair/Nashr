# Thakeen plan pricing — implementation plan

Design: `docs/superpowers/specs/2026-09-29-pricing-design.md`. Each phase ships as its own PR, runs `npm run check` and
`npx next build`, updates `docs/system/*` in the same commit, and adds or updates a test in `tests/` for every rule it
touches. No account pays yet, so no phase needs a customer migration; test and founder accounts are moved by the
founder console.

## Phase 0 — Teams (seats) · in progress

Design: `docs/superpowers/specs/2026-09-29-teams-design.md`. Seats 1 / 3 / 7, trial 3, sharing the account's credits,
chat allowance and brands. Owner-only actions checked in code.

## Phase 1 — Plans, credits, floor

- `src/lib/auth.ts`: `Plan` gains `business`; `PLAN_CREDITS` → trial 50, starter 300, pro 700, business 1500, agency
  custom (founder console sets it), enterprise folded into agency (keep the literal for old records, map it to agency
  on read).
- `src/lib/admin-stats.ts`: `PLAN_PRICE_SAR` → 299 / 499 / 999; agency from the account record (custom deal).
- `src/lib/brands.ts`: `BRAND_LIMIT` → unlimited on every plan (keep the per-hour creation rate limit).
- `src/lib/brand.ts`: `TASK_COST.weekly_plan` 1 → 2, `TASK_COST.followup_seq` 3 → 4.
- New `src/lib/pricing.ts`: one place for `PLAN_PRICE_SAR`, `PLAN_CREDITS`, `CHAT_ALLOWANCE`, `SEAT_LIMIT`,
  `MARGIN_FLOOR = 0.6`, `cheapestCreditUsd()`, `maxCostPerCreditUsd()`.
- Test `tests/pricing-floor.test.ts`: for every task type, `estimated cost per batch ÷ TASK_COST ≤ maxCostPerCreditUsd()`
  using the per-type estimates in `docs/system/costs.md` section 3 (moved into a typed table next to `TASK_COST`).
  Fails the build when a price, a credit count or a rate change breaks the 60% floor.
- `docs/system/costs.md` section 4 rewritten for the new tiers.

## Phase 2 — Chat allowance and model

- `src/lib/rate.ts`: monthly counter `chatm:{account email}:{YYYY-MM}` next to the hourly and daily ones; the limit is
  `CHAT_ALLOWANCE[plan]` (trial 30, 250 / 650 / 1,300, agency custom). Web chat and MCP `ask_noor` both count.
- Chat UI: "N messages left this month" and a clear pause message with the top-up link when it runs out.
- `src/lib/chat.ts`: conversation turns switch to `claude-sonnet-5` behind a flag, flipped only after the golden eval
  and a Gulf-dialect check pass (results recorded in the founder console quality tab).

## Phase 3 — Trial

- `src/lib/auth.ts` `createUser`: `trialEnds` 3 → 7 days. Trial chat allowance 30, seats 3, no video models.
- Copy: every "3 days" string in `src/lib/i18n.ts` and `src/lib/app-i18n.ts`.

## Phase 4 — Brand guardrails

- Onboarding of a second or later brand charges 9 credits (`ONBOARD_EXTRA_BRAND_COST`), shown before confirm, refunded on
  failure; the first brand stays free.
- Weekly plan cron (`src/lib/cron-batch.ts`): runs for the first brand by default; added brands carry
  `weeklyPlan: false` until the owner switches it on in the brand settings.

## Phase 5 — Media pricing

- Media catalog (branch `claude/api-list-517da7`): `credits = ceil((providerUsd + blobUsd) × 1.1 ÷ maxCostPerCreditUsd())`
  computed from `src/lib/pricing.ts`, with a test per model.

## Phase 6 — Payments, top-ups, annual, currencies

Blocked on the provider decision and the accountant (spec section 7).

- Top-up ledger separate from the monthly balance: packs 100 / 300 / 1,000 at 1 SAR a credit + VAT, `expiresAt` 90 days,
  spent after the monthly allowance, oldest pack first. `charge` / `refund` in `src/lib/credits.ts` learn the second
  pool under the same lock.
- Annual: 2 months free; the monthly renewal cron keeps granting credits monthly.
- Local price lists per country (SAR first, AED second), clamped to the floor by a test.
- ZATCA-compliant invoices (amount before VAT, VAT, total).

## Phase 7 — Pricing page and copy

- Tiers: Starter / Pro / Business self-serve, Agency "Contact us" (absorbs Enterprise). Each tier's headline names its
  human alternative. Outputs instead of credits ("≈ N posts or M articles a month"). Seats 1 / 3 / 7, unlimited brands.
- Remove "Extra seats SAR 99 / seat"; replace the "first 100 brands, two months free" line with the price lock for the
  first 100 paying accounts.
- ChatGPT only in a feature comparison. No model names on public pages.
- Arabic and English together; update `tests/content-claims.test.ts` for any new claim.

## Phase 8 — Review instrumentation

- Founder console: trial-to-paid conversion, tier mix, share of credits used per account, real $/credit per task type,
  top-up rate. Trigger the review at 50 paying accounts or 90 days.
