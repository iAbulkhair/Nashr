# OpenDots → Thakeen: what to adopt, what to adapt, what to skip

Study of [CopilotKit/OpenDots](https://github.com/CopilotKit/OpenDots) (MIT, alpha, cloned 2026-10-20 at its default branch), compared against Thakeen at `main` 70d1675. Both sides were read in code, not only in their READMEs. File references on the OpenDots side are to its repository; on the Thakeen side to this one.

## 1. The one-paragraph verdict

OpenDots is a **single-owner template** for "always-on AI coworkers": each agent (a "Dot") has instructions, per-tool switches, its own browser/computer, Slack and voice entry points, and every write goes through an approval card bound to the exact stored call. Thakeen is already ahead on everything a paying multi-tenant product needs (tenant isolation, roles and seats, credits and caps, version-hashed approval, exactly-once publishing, founder console, audited admin). OpenDots is ahead on **agent authority as a first-class, owner-controlled object**, on **re-checking that authority at the moment of execution**, and on **entry points beyond the web app** (Slack, voice, an agent computer). The right move is to import its *control model*, not its runtime: no CopilotKit Intelligence, no AG-UI rewrite, no SQLite, no single `OWNER_ID`.

## 3. What shipped on this branch

Rules 2330-2336; coverage in `docs/system/tests/2330-agent-tool-authority.md`; `docs/system/flows.md` section 91; `docs/system/permissions.md` "Agent tool authority".

- **Owner control.** Governance → "What each agent may do in chat". Each of Noor, Sami, Razan, Faris, Dana, Majed, Layan and Reem gets Allowed / Ask first / Not allowed for: create content, images, write workspace files, publish, import the catalog. Ask first exists only where a card can run the exact stored request (content and images).
- **Enforced in code, in four places.** The tool is not offered (`toolsFor`); a call naming it is refused from the setting read at that moment (`runTool`); Ask first always leaves a card, even when the owner's message asked for the work (`spendGate`); the card's Run re-reads the setting and answers 409 `revoked` if it was switched off since (`decideSpend`).
- **Honest prompt.** One line in the agent's workspace block says what is off or ask-first, so it does not promise work it cannot start.
- **Auditable.** Every change is a governance revision (`toolPolicy.noor.publish: on → off`), restorable, with who made it.
- **Safe rollout.** Expand only (rule 679). Old records read as all Allowed, which is today's behaviour; no conversion script.

## 5. What not to copy, and why

- **The single-owner identity** (`OWNER_ID`, one bearer token, a global settings row, connection routes with no ownership check). Every Thakeen key is scoped by `sc(u)`.
- **An empty Composio allowlist meaning "all toolkits".** Thakeen defaults to deny.
- **Composio and computer writes without per-call approval.**
- **Vendor lock on CopilotKit Intelligence** for threads, history and learning, and telemetry on by default to a vendor endpoint.
- **Process-local concurrency** (one job per process, one call per process, in-memory dedupe maps), which breaks with more than one server instance.
