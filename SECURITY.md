# Security policy / سياسة الأمان

Thakeen (ذكين) is a hosted service. There are no released versions to support: the only supported version is the one
running at https://thakeen.com, built from this repository's `production` branch.

ذكين خدمة سحابية، ولا توجد إصدارات منفصلة. النسخة المدعومة الوحيدة هي العاملة على https://thakeen.com.

## Reporting a vulnerability / الإبلاغ عن ثغرة

Please report privately, never in a public issue, discussion or pull request:

1. **Preferred:** GitHub private vulnerability reporting. Open the repository's **Security** tab and choose
   **Report a vulnerability**. Only the maintainers see the report.
2. If you cannot use GitHub: email hello@thakeen.com (the contact in https://thakeen.com/.well-known/security.txt) with
   the subject `Security`. Send the details only after we reply, through the GitHub advisory we open for you.

نرجو الإبلاغ بشكل خاص فقط: من تبويب **Security** في المستودع ثم **Report a vulnerability**، أو عبر البريد
hello@thakeen.com بعنوان `Security`. لا تنشر التفاصيل في issue عام.

Include what you can: the affected page or API route, steps to reproduce, the impact you observed, and whether any data
other than your own was reachable. Arabic or English.

## What to expect / ماذا تتوقع

- We acknowledge a report within 5 business days.
- We tell you whether we accept it and, if we do, keep you updated in the advisory until it is fixed.
- We credit you in the published advisory if you want to be named.
- There is no paid bug bounty.

## Testing rules / ضوابط الاختبار

In scope: https://thakeen.com and the code in this repository.

- Test only against accounts you created yourself. Never access, change or delete another customer's data; if you reach
  it by accident, stop, do not keep it, and tell us.
- No denial of service, load testing, spam, social engineering of our staff or customers, or physical attacks.
- Do not test third-party services we use (hosting, payments, email, AI providers) through us; report those to the
  provider.
- Give us a reasonable time to fix the issue before any public disclosure.

We will not pursue legal action against research done in good faith within these rules.

Out of scope: missing best-practice headers with no demonstrated impact, self-XSS, clickjacking on pages with no
sensitive action, rate-limit reports without a security impact, and reports generated by automated scanners alone.
